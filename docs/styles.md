# 37 种画风参考

[返回首页](../README.md)

共 **37 种画风**，按 6 个系列收起展示。点击系列标题展开，点击样图查看原尺寸。选中后直接说编号或名称，例如“用 S10 手绘涂鸦风格”。

样图只提供线条、材质、配色和造型风格，角色仍以你上传的主图为准。画风不绑定动作；动作由本次主题、文案和角色决定。需要灵感时可查看[动作参考库](actions.md)，也可以设计库中没有的动作。

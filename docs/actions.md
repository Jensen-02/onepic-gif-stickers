# 动作参考库

[返回首页](../README.md) · [画风参考](styles.md)

共 **128 个动作灵感，16 个主题**。这是一份可选参考，不是动作白名单，也不是必须匹配的文案词典。模型可以改编、组合，也可以根据用户主图、主题与文案设计库中没有的动作，无需为新动作请求许可。用户明确指定的动作优先。

各主题默认收起，点击标题展开。每条提供聊天含义、文案例子、轻／大动效、角色动作与循环思路。这些只是设计起点，可以换道具、改幅度或另创动作，不必按编号选取。

轻动效也需要完整过渡；大动效也要安排起势、重心与收势。循环建议需结合实际生成结果检查。

## 画风与动作分开设计

同一个动作可以用不同画风表现，同一种画风也能表现许多动作。国风、赛博、魔法等分类提供题材与道具灵感，不要求更换用户角色的面孔、服装或物种。画风仍按用户要求与[风格参考](styles.md)选择。

下面以“抬掌示意稍等”为例，展示可选的表现变化；不是每种画风只允许这些变化：

| 表现方向 | 可借用的处理 |
|---|---|
| 手绘涂鸦 | 手指和眉眼用简洁线条强调，少量动作线辅助；手臂本身仍要连续移动 |
| Q 版卡通 | 放大手掌和眼神的反差，头身比例保持角色设定 |
| 像素风 | 用清晰轮廓表达抬腕和张掌，保持像素网格，不靠闪帧代替动作 |
| 毛绒或黏土 | 用柔软关节和材质形变表现抬手，保留五官、接缝或纹理位置 |
| 发条或气球造型 | 按现有转轴或扭结处理弯曲，不凭空增添关节或气球段 |
| 国风或赛博题材 | 可让衣袖随手臂展开，或让护腕弹出简洁暂停符号；角色手势仍是主要信息 |

素材可以换，动作的聊天含义不必换。反过来，同一句“不想上班”也可以推开咖啡、把工牌翻过去、抱着闹钟躲起来，或另创完全不同的表演。不要把换道具当作整套动作的唯一变化。

宠物先按真实肢体结构设计。若用户未要求拟人化，不给猫狗加人类手指、站姿或服装；人类动作可以改成爪、尾巴、耳朵、头部和身体动作。默认半身构图，确需跑跳时再给出大头小身体全身与足够运动空间。

本库是文字设计参考，不代表 128 条都已有 GIF 成品或通过动态验收。实际制作仍按[创作设计](../skills/onepic-gif-stickers/references/creative.md)规划，按[验收方式](../skills/onepic-gif-stickers/references/quality.md)检查。

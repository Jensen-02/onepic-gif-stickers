# 一图成套 · GIF 表情包工坊

Codex 专用技能：上传一张主图、说一个主题，使用 Codex 内置图片生成能力制作一套独立 GIF 表情包。

调用名保持 `$theme-gif-stickers`。例如：

> 根据这张照片，把我做成Q版，制作8张日常聊天表情包。

默认12张、512px白底、2–6字字幕、贴合文案的轻动作。可指定数量、画风、无字版或大动作。角色样张和静态合集是中间产物，默认继续做完GIF，不需要额外说“继续”。

本技能不要求另外配置图片 API；需要当前 Codex 会话可用的内置图片生成工具。本地合成使用Python3.10+、Pillow13.x与可用字体。运动补帧属于可选能力，不默认下载安装大型模型。

默认自动文件检查加快速播放预览，异常才精检；合成器默认不导出全量逐帧PNG，需要时使用`--review-frames`。没有实际观看播放时应标明待动态验收，不把技术通过当成视觉通过。

内置37张风格参考，见[风格说明](references/style-library.md)与`assets/styles/index.html`。用户主图决定身份，样图只提供画风。

最终交付每条表情对应的独立 `.gif` 文件和整套 ZIP。生成工具返回静态图后继续制作，不停在角色样张或静态合集；已能直接输出真实 GIF 时优先使用，跳过姿势合成。

版本：0.3.1预览版。完整安装、演示、问题反馈和MIT许可见[项目主页](https://github.com/Jensen-02/onepic-gif-stickers)。

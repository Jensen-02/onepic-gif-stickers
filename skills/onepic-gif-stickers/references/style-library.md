# 风格参考库

目录：`../assets/styles/`。共37张用户指定的预生成样图；可用编号、名称或自然语言选择。完整清单和路径见`style-catalog.json`，可视化浏览页为`../assets/styles/index.html`。

## 两种参考严格分工

- `identity_reference`：用户本次上传或明确指定的主图，决定主体是谁、物种、面部／花色、头发、眼镜、服饰与关键配件。
- `style_reference`：库内选定样图，只决定画法、材质、线条、着色与夸张程度。样图出现的黑发、眼镜、白衣、性别、年龄和姿势不自动迁移给用户主体。
- 本条生成后确认的母版：约束整套作品的一致性，仍以用户主图为身份来源。

给生成工具传图时逐张说明角色，例如“图1是唯一身份主参考；图2仅借用涂鸦线条与配色；保持图1的物种、外貌和独特特征”。外貌冲突时用户主图优先；明确要求变装、拟人化等才改变对应特征。不用库内角色替代缺失的用户主图。

样图的微笑、半眯眼、歪头和姿势不属于必须保持的画风。不同条目的神态与姿态应由各自文案决定；明确区分跨条目的风格一致与单条动画内的连续性，避免整套表情雷同。

## 选择与制作

用户指定编号／名称时直接匹配。近似名称可据语义选最接近项并简短告知；用户要看风格时展示画廊，不逐张加载全部原图。用户未要求换风格时保持主图样式。

按用途重新设计半身或大头小身体构图。库内全身姿势不是必须复制的动作。画风说明只参考 catalog 中的 style_notes，不提供或限制动作。具体文案、道具、轻／大动效与循环都由本次主题决定。需要灵感时可读[动作参考库](action-library.md)，其中示例可改编，也可完全另创。

这些是静态画风参考，不代表37种画风都已经通过GIF动态质量验收。生成时检查该风格容易漂移的部位，必要时简化纹理或动作。

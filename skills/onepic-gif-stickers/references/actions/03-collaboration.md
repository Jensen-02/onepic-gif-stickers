# 工作协作

以下是可改编的动作灵感；也可以设计库外动作。文案与幅度均为示例，不绑定画风。

| 编号 | 聊天含义／文案例子 | 幅度 | 角色动作 | 循环思路 |
|---|---|---|---|---|
| A017 | 汇报进度／马上就好 | 轻 | 一手比稍等，另一手在键盘上点两下，眼神仍盯着屏幕 | 手势落回，敲击手回到原键位 |
| A018 | 接下任务／安排上了 | 轻 | 拿起印章对准文件，稳稳盖下，再抬眼确认 | 印章离纸回到印台，印迹不要逐轮叠成墨团 |
| A019 | 展示完成／改完了 | 轻 | 把带勾选图形的卡片翻向对方，指尖点一下完成项 | 卡片翻回自己这面；不用动画擦除勾选 |
| A020 | 求协助／救救孩子 | 轻 | 双手托起厚文件夹，抬眼求助，手臂因重量略沉 | 文件夹放回桌沿，再托起，不改变厚度 |
| A021 | 推卸任务／这锅谁的 | 大 | 侧身把一口小锅推到桌边，装作若无其事地望向另一侧 | 回头发现锅仍在，主动拉回；推拉过程都由手完成 |
| A022 | 主动承担／这锅我背 | 大 | 把带背带的玩具锅背上肩，挺胸站稳，扶正背带 | 放低锅到腰侧，再重新背好；肩带连续可见 |
| A023 | 请求解释／听我解释 | 轻 | 拉开小卷轴图表，指着一个圈，急切地看向对方 | 手动合起卷轴再打开，图形不随机变换 |
| A024 | 暂停讨论／暂停一下 | 轻 | 按响桌铃后把手掌留在半空，眼神示意停一停 | 手放回铃旁，铃的回弹随后停止 |

# 情绪反应

以下是可改编的动作灵感；也可以设计库外动作。文案与幅度均为示例，不绑定画风。

| 编号 | 聊天含义／文案例子 | 幅度 | 角色动作 | 循环思路 |
|---|---|---|---|---|
| A065 | 疑惑／啥意思 | 轻 | 把便签从远处拿到眼前，眯眼又挑起一边眉毛 | 便签放远，头部回正；不依赖便签上的文字才能看懂 |
| A066 | 无言以对／无语住了 | 轻 | 缓缓闭眼，捏住鼻梁，手垂下时眼神失去光彩 | 松开鼻梁、睁眼短停，再闭眼 |
| A067 | 发火／气死我了 | 大 | 身体前倾，双手拍桌后迅速抱臂，嘴巴抿紧 | 放下双臂回到桌边，再蓄力；桌面接触后有回弹 |
| A068 | 大笑／笑不活了 | 大 | 一手捂肚子，身体弯下，另一手扶住桌边笑得直不起腰 | 稍直起吸气，再弯腰笑，避免整张图振动 |
| A069 | 震惊／还有这种事 | 大 | 身体后仰、眼睛睁大，随后凑近手中的手机再看一眼 | 回到中间姿势，手机不跟着脸一起变形 |
| A070 | 心态崩了／我裂开了 | 轻 | 双手捧着两半心形拼片，试着合拢却又松开，表情僵住 | 拼片围绕同一接缝分合；角色脸部不真的裂开 |
| A071 | 委屈／委屈巴巴 | 轻 | 嘴角向下，攥着袖口轻擦眼角，再抬眼看对方 | 手落回胸前，眼泪可少量出现，不无限积水 |
| A072 | 拒绝倾听／我不听 | 大 | 两手把耳罩按紧，脑袋左右各偏一下，眼睛闭紧 | 头回正，手稍松再按紧，耳罩始终贴合头部 |

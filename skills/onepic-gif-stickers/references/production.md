# 制作与工具

## 能力边界

本技能专用于 Codex，默认调用当前会话内置图片生成能力，用户无需单独配置图片 API。按内置工具的参数与权限使用参考图并取得生成文件；模型字段记录实际返回值，没有则写unknown，不能写死未经验证的模型ID。工具未开放或额度不足时说明具体阻塞，不改成要求普通用户自行部署生图服务。

- 原生GIF：当前内置工具支持时优先使用，实际返回可解码多帧GIF后进入检查和打包，不重复生成姿势或重新合成。
- 参考图图像生成：当前工具只提供静态输出时，保留模板身份与本条道具设计，分小批生成真实姿势，再本地合成GIF；可使用单帧或小型等格姿势页。静态图返回不代表任务完成。
- 视频生成：现有工具支持且用户接受此路线时使用，按实际视频取帧；不能把工具未开放的路线宣传成已可用。
- 只有静态工具也可制作GIF：图像生成姿势，程序按序编码；其流畅度取决于姿势连续性，不保证所有风格都能成功。

使用当前环境的图像生成能力生成和修改角色画面。不要用几何绘制替代用户角色，或用整图仿射变换假装肢体动作。程序用于切出已生成帧、统一画布、字幕与编码等确定性工作。

## 连续姿势

为每条写清起始姿态、视线、手与道具接触点、姿势变化和复位。所有帧保留同一相机、角色比例与材质。眼镜和动物花色是重点检查项。

小动作先尝试少量真实姿势，检查相邻差距后补过渡；不要为凑10帧把4张图重复。连续动作缺少关键过渡时要补画，或公开说明需要更可靠的生成路线。

默认流畅版要求运动轨迹连续，不把“帧率达到某数值”当通过。可从约20–25帧/秒尝试；细小动作、像素风或有意停顿可用不同节奏，按实际播放判断。循环时长由完整表达决定，不固定每条2.5秒。

运动补帧可使用当前可用且经过核验的插帧工具。它估计相邻姿势之间的运动，不负责设计缺失动作；不默认增加付费视频路线或无条件安装大型模型。检查眨眼、嘴形、手指、眼镜、道具边缘和遮挡交接；像素画尤其检查线条、色块是否被涂抹。坏帧不能靠继续提高帧率修复。

整圈包含末帧到首帧的过渡。核实插帧工具实际时间映射：部分实现会把末端延长成相同帧，按预定循环区间取帧，避免无意停顿。记录生成姿势数、补帧方法、真实解码帧数与时长，不把补帧输出称为逐张生成的原画。

使用姿势页时，实际检查分格数量、边距、顺序和跨格元素；均等切割只在图像确实符合网格时成立。保留相同提取尺寸与全序列统一缩放。角色主动抬头、弯腰或挥手是动作，不应按每帧人物包围框重新居中或缩放掉。

## 背景与字幕

白底为默认交付，透明和简约场景均可配置。支持真实Alpha的工具可直接生成透明背景；不普遍强制绿幕。必须抠色时，仅移除与边缘连通的背景区域，保护衣服与眼睛中的同色内容。此版本合成器不负责抠色。

文字默认开启；关闭时不添加画面文字，构图不保留专用字区。开启时默认顶部深色粗圆字加白描边，每条内全帧一致。先选择有中文覆盖的字体并检查实际字形；使用者提供字体时核查再分发需求。本包不附商业字体。源姿势不含字幕，补帧后再叠字，避免字体被拉扯；合成器自动缩小过宽文字，不压缩拉伸字体。切换有字／无字时复用干净动作帧重新排版，不重新生成动作。已有素材本身含字时需先取得干净源图；show_text=false只关闭后期叠字，不能删除源图中的文字。

GIF仅能表达有限调色板与二值透明；对半透明霓虹与柔边，白底GIF通常更稳定，需要保留半透明时可另交动画WebP。WebP不是本版本合成器的现成功能，需要使用可用编码工具并验证后再交付。

## 导出

依赖：Python3.10+与Pillow。项目中已可用则不重复安装。
```
python scripts/compose_pack.py --manifest /path/to/render.json --output /path/to/new-version
```

输出目录必须不存在或为空，避免覆盖已接受版本。脚本使用统一画布映射、顶部字幕与整条共享调色板，按每帧时长保存GIF；读取最终GIF得到真实时长和帧数，生成动态画廊、检查记录及候选ZIP。默认不保存逐帧PNG与检查拼图；发现异常或需要精检时加 `--review-frames`，仅对相关条目导出到新的目录。此开关不改变GIF动画内容。

本版本输入是独立帧；需要切网格、抠图、提取视频或转WebP时，代理根据实际素材调用可用工具，不声称脚本已有这些能力。平台限制以当前官方资料或用户指定要求为准，512px为项目默认值，不代表任何平台认证。

# 创作设计

## 角色约束

记录主体类别、发型或毛色分区、面部比例、眼镜、服饰结构、配色和标志配件。不要把一张图中不可见的背面当作已知事实。选择能用现有视角表达的动作；复杂转身确有需要时才补参考。

样张的站姿不是整套必须沿用的姿势。主题变化不应顺带改变脸型、头身比或手脚结构。身体、表情、视线和道具共同讲清动作。

聊天构图优先半身：胸像突出表情，腰部以上为双手和道具留空间。大头小身全身构图用于明确需要腿脚的动作。不要为了遵守全身模板而让聊天图中的脸过小。由全身改半身时使用生成工具重新设计合适取景，检查发型、配件、手部与身体边界；不裁掉动作关键部位。

## 系列文案

先理解用户想怎样聊天，再铺开情境。例如上班主题可包含：开工、疲惫、拖延、回应、拒绝、求助、协作、下班。根据数量和语气选择覆盖，不硬凑固定比例。

默认中文2–6字，去掉空格后计数；保留明确指定的较长文案，并记录例外。避免仅换近义词、用攻击性表达代替幽默、或把整套做成同一个困倦表情。语言与强度可由用户调整。

每条规划至少包含：
- caption：短文案／内部含义；无字版保留作动作依据和文件标签，不绘入画面。
- show_text：是否显示画面文字，默认开启，可整套或单条关闭。
- motion_profile：轻动效或大动效，描述动作幅度，不代表流畅度等级。
- moving_parts / stable_parts：哪些部位运动、哪些特征与接触点应保持稳定。
- chat_intent：用户在什么聊天情境下发送它。
- visible_action：主角究竟做什么，必须可从画面观察。
- props：道具及角色如何接触它；无必要时为空。
- comic_beat：可读的反差或夸张点；温柔日常可以只有小情绪，不强加笑料。
- action_beats：起始、变化、表达峰值、复位或连接方式。
- loop_strategy：为何再次开始在语义和位置上成立。

## 语义审查

先看整套情绪是否有区分，再看单条动作。统一的是角色身份与画法，不是脸上同一种表情；为每条按场景确定眉形、眼睛开合、视线、嘴形与姿态，例如期待、馋、豪爽、满足、顽皮、专注、陶醉、松弛。表达可以夸张，但不随意更换角色。若遮住道具后大多数条目仍是同一张笑脸，重设对应条目的表演。上述情绪仅是示例，不固定套用或强凑不同。

不要将一张有鲜明神态的母版同时当作所有条目的表情模板。使用母版时明确“只保留身份和画法，本条神态按表演设计”；存在锚定时回到用户主图和单独画风参考，重新设计本条关键姿势。各条可采用不同朝向和构图，同一条内再保持相机与比例稳定。

遮住文字，看画面能否辨认主要意图；再把文案换成另一条，若动作同样完全适用，说明设计可能太泛。此检验由模型/人判断，关键词匹配或像素差异不能代替。

“收到”可看向消息再短点头，不能只是整图弹跳；“不想上班”可手搭键盘、犹豫、收手托腮；“下班了”可把工牌翻到背面、露出笑容并轻挥手，避免无缘由的整图飞出。

道具承载动作含义，不是背景装饰。允许每条使用不同道具，系列统一用色、线宽和材质。浅场景只保留必要的桌沿、椅背、窗角，镜头固定。不要擅自给所有条目加同一张办公桌。

## 动作幅度与表演

轻动效：一个局部主动作，必要时配一个小表情；身体与镜头大体稳定。例如手腕轻摇扇子、指尖敲桌、眼神移向消息、把杯子推远一点。道具运动要有可解释的原因。少动几个部位，不等于删掉必要过渡帧。

大动效：明显的肢体、重心或位置变化，例如趴倒、转身跑开、双手举起庆祝。规划预备、主动作、收势和循环复位，检查遮挡、接触与运动边界。局部轻动效也可有强烈情绪，不能用整幅猛烈摇晃代替表演。

先写“表达什么”，再写“谁的什么部位，朝哪里，以什么节奏变化”。例如“我不干了”的轻版可按住文件并缓慢推远，大版可抱臂转身背对桌面；两版都须看得出拒绝。

无字版优先安排清楚眼神、手势和必要道具。复杂文字梗不能只靠画面表达时，可转成直观情绪或行为，不偷偷把文字放到衣服、道具、气泡或背景里。

用户给动图作动作参考时，区分角色来源与动作参考。观察运动部位、幅度、节奏和循环方式，不把参考角色、路径、截图或逐帧文件写入skill；只保留通用设计原则。

更多可选灵感见[动作参考库](action-library.md)。这些例子不限制主题、画风或可用动作，模型应优先按本条聊天含义另行设计。

## 上班主题示例

以下仅展示设计方式，实际文案由主题与语气生成，不作为关键词动作字典。

| 文案 | 使用情境 | 画面与动作 | 循环处理 |
|---|---|---|---|
| 不想上班 | 开工前抗拒 | 手伸向键盘又收回托腮，半垂眼皮 | 托腮短停后放手回起点 |
| 让我缓缓 | 暂时不想接任务 | 一手扶杯，一手抬掌，肩膀稍松 | 手掌缓慢放回 |
| 电量告急 | 精力耗尽 | 撑脸的手慢慢滑一点，眼皮耷拉，随后重新撑住 | 回到支撑姿势，保持脸部形状 |
| 又开会啊 | 被叫去会议 | 看向桌上话筒，轻轻推远一点又犹豫收回 | 由手明确带回话筒，不让道具自行滑动 |
| 收到收到 | 确认信息 | 瞄一眼手机，抬眼短点头 | 视线回到手机 |
| 马上就好 | 请求稍等 | 一手比“等一下”，另一手点两下键盘 | 手势回落，保留节拍 |
| 救救孩子 | 求协助 | 双手托起未完成文件夹，抬眼求助 | 放回胸前低处 |
| 先喝一口 | 短暂休息 | 杯子从胸前举到嘴边，轻啜后放下 | 真实放回，不倒放喝水 |
| 别催了 | 对催促回应 | 把小计时器转向自己，抬掌示意 | 手放回计时器旁 |
| 我先下线 | 结束在线 | 手指轻按桌面小灯开关，挥一下手 | 暗灯停顿后明确按回，作为重复表演 |
| 准点下班 | 下班期待 | 看腕表、扬眉，轻拍包带 | 回看腕表 |
| 明天再说 | 暂缓讨论 | 将便签贴在文件夹封面，轻拍一下 | 改用手持便签反复示意可更易循环；选择后统一表演 |

对不自然的循环优先重设计动作；不必坚持示例中的复杂道具过程。

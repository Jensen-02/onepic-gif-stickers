# 动作参考库

这是一份可选的创作灵感库，不是动作白名单，也不是必须匹配的文案词典。模型可以改编、组合这些例子，也可以根据用户的主图、主题、文案和道具设计库中没有的动作；不需要为使用新动作请求许可。用户明确指定的动作优先。

画风与动作独立选择：同一个动作可以用不同画风表现，同一种画风也可以表现不同动作。不要因为选了某种画风，就固定使用某几种手势。需要调整的是动作的表现方式、角色结构与材质连续性，而不是把画风绑定到动作清单。

## 怎么参考

先理解这张表情包在聊天里表达什么，再决定角色如何表演。以下每行提供一种可能性，不要求照搬文案、道具或幅度；也不要求一套作品覆盖所有类别。轻动效指参与运动的部位较少，不等于生硬停帧；大动效同样需要合理的过渡与收势。

## 轻动效示例

| 聊天含义 | 文案例子 | 动作灵感 | 表演与循环考虑 |
|---|---|---|---|
| 打招呼 | 在呢 | 抬眼看向对方，抬手轻挥 | 手腕带动手掌，放回起点 |
| 确认 | 收到 | 看一眼消息，抬头点头 | 点头后视线自然回落 |
| 疑惑 | 啥意思 | 视线移向问号便签，挑起一边眉毛 | 头部轻侧再回正，不必固定问号道具 |
| 拒绝 | 不想上班 | 手伸向鼠标又收回，托住腮 | 用犹豫和收手表达抗拒 |
| 暂缓 | 让我缓缓 | 抬掌示意，缓缓放下 | 手势是主动作，疲惫表情配合 |
| 催促 | 搞快点 | 指尖敲桌两下，眼神看向对方 | 敲击有接触点和节拍 |
| 想吃 | 给我一口 | 眼神跟着食物移动，悄悄伸出手 | 手收回后再开始，食物不要自行消失 |
| 休息 | 先喝一口 | 举杯、轻啜、放下 | 喝水过程不直接倒放 |
| 困倦 | 再睡五分 | 抱紧靠垫，慢慢闭眼又勉强睁开 | 让抱紧动作和眼神共同表达困意 |
| 无奈 | 没钱了 | 打开空钱包，一只飞蛾飞出，低头看钱包 | 合上钱包作段落结束；飞蛾离开画面后再复位 |
| 害羞 | 怪不好意思 | 目光躲开，手指轻碰脸颊 | 眼神与手势配合，不只加腮红闪烁 |
| 鼓励 | 你可以的 | 抬起握拳的手，轻轻向前送一下 | 拳头回落，保持人物朝向 |

## 大动效示例

| 聊天含义 | 文案例子 | 动作灵感 | 表演与循环考虑 |
|---|---|---|---|
| 逃离 | 溜了溜了 | 探头看一眼，转身小跑离开 | 可借门框遮挡衔接下一轮 |
| 庆祝 | 好耶 | 蹲低蓄力，小跳举手，落地 | 留出顶部边距，落地后回到站姿 |
| 疲惫 | 我躺了 | 双肩松下来，身体趴向靠垫 | 安排合理起身或遮挡复位，不倒放跌落 |
| 亲近 | 抱抱 | 张开双臂向前拥抱，再收回 | 给手臂留空间，避免伸出画布 |
| 出发 | 下班啦 | 抓起包，起身转向门口 | 包带、手部接触连续，按需要用全身构图 |
| 生气 | 气死我了 | 身体前倾，双手拍桌后抱臂 | 拍桌的冲击与回弹可夸张，不把整图乱晃当表演 |
| 惊喜 | 还有这种事 | 身体后仰，睁大眼睛，再凑近看 | 重心和面部表情一起变化 |
| 好笑 | 笑不活了 | 捂着肚子弯腰笑，再稍稍直起 | 表情与肩部节奏配合，保留脸部辨识度 |

## 允许超出这些例子

同样表达“不想上班”，可以推开咖啡、把工牌翻过去、抱着闹钟躲起来，也可以结合角色习惯设计完全不同的表演。无需先在本库里找到对应条目。动作是否成立，应看它能否传达文案、保持角色身份、符合接触关系并连续播放，而不是看它是否出现在库中。

本库是文字设计参考，不代表每个例子都已有成品或通过动态验收。实际制作仍按[创作设计](creative.md)规划，按[验收方式](quality.md)检查。
